# Tripower Mold Tech — Web Application

Modular **Astro + Tailwind CSS (v4)** web application for **Tripower Mold Tech**, a precision injection mold toolroom in Thirumudivakkam, Chennai.

---

## 🌿 Environment & Port

* **Branch:** `dev` (Active Development)
* **Live Custom Domain:** **[https://tpmt.work.gd](https://tpmt.work.gd)** *(HTTPS / Automated GitHub Pages)*
* **Assigned Port:** **`9000`**
* **Local URL:** [http://localhost:9000/](http://localhost:9000/)
* **Network URL:** [http://192.168.1.174:9000/](http://192.168.1.174:9000/)

---

## 🚀 Quick Start

Ensure you have Node.js installed (v20+ recommended).

```bash
# Install dependencies
npm install

# Start local server on port 9000
npm run dev

# Build static production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🧭 Routes Summary

| Route | Page | Purpose |
| :--- | :--- | :--- |
| [`/`](http://localhost:9000/) | **Home** | Facility telemetry, high-impact stats, core capabilities, and instant RFQ |
| [`/about-us`](http://localhost:9000/about-us) | **About Us** | Toolroom profile, precision engineering standards, and leadership |
| [`/services`](http://localhost:9000/services) | **Services & D3** | Plastic molds, insert dies, D3 CAD/CAM/CAE interactive phases |
| [`/capabilities`](http://localhost:9000/capabilities) | **Capabilities** | Makino CNC, Wire EDM, CMM metrology, and project portfolio filters |
| [`/contact`](http://localhost:9000/contact) | **Contact Us** | Plant address, direct WhatsApp / call, plant tour scheduler, file upload |
| [`/rfq`](http://localhost:9000/rfq) | **RFQ Portal** | 2D/3D CAD (.STEP / .IGS) submission & instant feasibility quote |

*(Legacy routes like `/services-d3-solutions`, `/capabilities-portfolio`, `/contact-us`, and `/rfq-portal` are also fully supported).*
